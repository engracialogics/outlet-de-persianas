# Outlet de Persianas — catálogo (exportado)

Catálogo en línea de las piezas outlet (enrollables blackout) de Outlet MID Persianas.
Archivo único `index.html` exportado desde Muse; no hay que editarlo a mano.

## Despliegue

- Hosting: **Firebase Hosting** (plan gratuito Spark), proyecto separado del de
  Mexicana de Persianas / customshadows.
- Despliegue automático: cada push a `main` despliega solo mediante la integración
  de GitHub Actions de Firebase Hosting.
- Dominio: `outletpersianas.com` (comprado en Spaceship), conectado en Firebase
  Hosting > Dominios personalizados.

## Actualizar el catálogo

1. Editar el artefacto `outlet-de-persianas` en Muse.
2. Exportar (`artifact.export`) y reemplazar `index.html` por el archivo nuevo.
3. Commit + push a `main`. El despliegue es automático.
